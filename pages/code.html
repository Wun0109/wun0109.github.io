程式應用

AI／Python 課程的練習作品，以 OpenCV 與 MediaPipe 為主。

影像處理基礎

  • YouTube 串流 × OpenCV串流播放 YouTube 影片
  • 即時交通影像串流串流高公局即時影像
  • 灰階、模糊與邊緣檢測處理後合併展示
  • 圖片裁切與區塊比較原圖與裁切圖對照
  • 自製繪圖板繪製圖形與文字
  • 攝影機擷取與截圖儲存鍵盤快速存檔

MediaPipe 偵測與辨識

  • 物件偵測圖像、攝影機與 YouTube
  • SelfieSegmentation即時背景替換
  • 人臉偵測標出眼、鼻、嘴、耳
  • FaceMesh468 點與嘴部貼圖
  • Pose 姿勢偵測骨架與彎舉統計
  • 手部追蹤指尖互動小遊戲
  • 手勢辨識關節角度與 Teachable Machine

整合應用

  • Streamlit 即時辨識網頁式攝影機與串流
  • Gemma3 多模態文字、語音、圖片輸入
  • AI 教學模擬器（獨立專題，進行中）語音、學生表情模擬與教學建議
